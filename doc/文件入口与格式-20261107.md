# 文件入口与格式

日常编辑优先保存 `.awproject` 写字项目，机器程序使用 `.nc` / `.gcode`。这两种文件各自独立：打开G代码不能还原原始文字、字体选择与区域布局。

## 统一打开

菜单“文件 → 打开”和主界面左侧“打开文件”支持写字项目、文字/PDF及原有图形、G代码格式。项目进入写字设置；`.txt` 按 UTF-8 正文导入；PDF 提取文字后按当前纸张重新排版。文字导入会确认是否替换正文。书写任务进行中禁止切换项目或导入文字。

两个排版页均提供“写字项目”和“生成与运行”分组：

- 写字项目：打开项目、保存项目、导入文字／PDF、导出PDF。
- 生成与运行：生成预览、生成并载入、打开G代码、导出G代码。普通正文页额外保留应用报告和连续排队检查。

主界面左侧“文件”卡片为“新建项目、打开文件、保存项目”。新建前会提示正文和区域将清空，现有机器配置仍保留。菜单原有的程序保存操作明确标为“保存G代码”。

右侧状态区显示写字项目文件名、修改标记及已载入的程序信息。保存/打开项目后更新文件名；文字和页面设置改变后显示“已修改”。

## 其他格式

- `.pdf`：查看、打印、交换文字；不替代可编辑项目。
- `.awtemplate`：区域布局模板，在“区域模板”管理。
- 机器配置 `.json`：机器笔控、方向和速度等配置，在“机器配置文件”管理。

机器配置和项目仍分开保存，不把实机参数悄悄混入项目。项目内字体使用路径和指纹引用，换电脑时需一并迁移字体文件。

## 验收

1. 从文件菜单打开 `.awproject`，确认正文、页数设置、区域及项目文件名恢复。
2. 修改正文，确认出现修改标记；保存项目后标记清除。
3. 从两个排版页点击“打开G代码”，选择 `.nc`，主界面应显示程序预览。
4. 导出G代码后重新打开，确认仅载入机器指令；要继续改文字则重新打开原项目。
5. 从统一打开入口选择文本/PDF，确认替换后正文可重新排版。

项目恢复和文件名回归已加入专项检查；两个排版页的布局守卫采用更新后的按钮名称。
