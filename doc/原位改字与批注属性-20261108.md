# 原位改字与批注文字属性

后续更新：[纸面对象与分区使用说明](纸面对象与分区-使用与测试-20261108.md)。新版交互已改为单击选中字、显示蓝框，再双击修改；直接双击未选中字不会弹窗。

入口：写字配置 → 纸面编辑。使用 `artifacts/autowriter/Release/GRBL-Plotter.exe`。

## 原位修改已有正文

选择顶部“正文改字”，点击灰色正文；在“选择/移动”工具下也可以双击正文。输入框会出现在这一行的位置，带入该行的原始文字，并把光标放在点击附近。

- 直接输入添加文字，Backspace/Delete 删除，选择文字后输入可替换。
- 点“应用改字”或按 Enter，立即重新排版。
- Shift+Enter 可在这段文字中插入换行。
- 点“取消”或按 Esc，不应用这次原位输入。
- 点击整个编辑器的“撤销/重做”，可以恢复已经应用的改字。
- 整个编辑器点“应用并关闭”才提交到主项目；点整个窗口的“取消”不提交。

原位编辑作用于当前显示行，可能是自动换行后的一段正文。跨行合并、大段替换或全文编辑，仍可用同窗口的“编辑正文”侧栏；不需要退出纸面编辑器。插入/删除后，其余文字会按原字体、字号、页面与环绕规则重新排版，不是在原路径上覆盖一个白色矩形。

此功能要求正文仍保留原文字，例如从 `.awproject` 打开的写字项目。单独的G代码或已经转成路径的字形没有可靠文字身份，不能自动还原成可输入的文字。空白处任意位置的新增文字请用“文字批注”。

## 批注独立字体与大小

选“文字批注”在纸面点击，或选中已有文字批注点“修改批注”，会打开“文字批注 · 独立文字属性”。可分别设置：

| 属性 | 含义 |
|---|---|
| 批注字库 | 从已发现的笔画字库中选择，与正文字库独立 |
| 字号 mm | 笔迹字身高度，使用毫米，不是 Word 的 pt 字号 |
| 字距 mm | 字符之间的额外间距 |
| 行距 mm | 多行批注的额外行距 |

新批注默认取当前正文参数作为初始值，确认后独立保存。旧批注没有独立属性时，第一次修改也以当前正文参数为初值。字库缺字、文件缺失或批注超出纸面会报错，原对象不会被覆盖。

修改已有批注时保留它的对象编号、位置和正文绑定；按照这次选择的文字属性重新绘制。此前对对象做过手动拖拽缩放时，再修改批注会按属性值重绘，而非自动推算拖拽后的字号。

这里选择的是本软件可用于写字的笔画字库，不是直接调用任意 Windows 系统字体；系统字体轮廓转换仍使用独立的“从文本创建G代码”窗口。

文字批注一旦“转为笔画”，便不再支持改字，需要撤销转换或重新创建批注。

## 快速测试

1. 正文填“工王”与下一行“王工”，打开纸面编辑。
2. 选择“正文改字”，点击第一行，改成“工工王”并应用，确认下一行仍在；再删成“王”，确认正文和预览一起变化。
3. 撤销一次应恢复上一版本。再打开原位输入框，输入后取消，正文应不变。
4. 创建批注“工王”，字库选可用的笔画字库，字号 8 mm、字距 2 mm、行距 3 mm；确认后应出现对应笔迹。
5. 选中它点“修改批注”，字号改为 12 mm；批注应实际变大，位置不变，正文的字号不变。
6. 如果批注绑定过正文，修改文字或属性后，绑定应保留。
7. 保存项目、重新打开，批注文字属性及形状应保留。生成预览、导出PDF/G代码后，也应使用修改后的笔迹。

含独立批注属性的项目内部版本为 5，后缀仍是 `.awproject`；新版兼容版本 1～5，旧程序会拒绝版本 5，避免丢失文字属性。
