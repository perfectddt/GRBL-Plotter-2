# AutoWriter 功能状态

当前入口是 [发布入口](AutoWriter-发布入口.md)。程序为 `artifacts/autowriter/Release/GRBL-Plotter.exe`，窗口标题版本 `2026.10.11`。`artifacts` 不进 Git；本机没有这个程序时，用 `scripts/publish-autowriter.ps1` 重新生成。

三类状态不能互相代替：

- **已完成**：代码已有，并且用户在纸面上确认过。
- **已开发，尚未实机**：代码和离线检查已有，纸面、断连或报警还没有用当前程序验收。
- **未完成**：没有做成可用功能，或只保留了对照截图里的需求。

## 已完成

这些有 2026-10-07 前后的实机记录，不需要再当作新功能开发。

| 功能 | 依据 |
|---|---|
| 开始、暂停抬笔、恢复、停止抬笔并回工作原点 | 短笔画、长直线、应用偏移后的流程，用户已确认 |
| 预览方向与纸面一致 | 方向修正 R7c |
| 编辑器换行与真实笔迹行距 | 用户确认换行修复有效；行距按墨迹间隙排布 |

## 已开发，尚未实机

下面都在当前程序里。离线检查已通过，但还没有用这版程序在机器上写出来验收。

| 功能 | 现在的行为 | 还缺的验收 |
|---|---|---|
| 普通分页、项目保存、上次设置恢复 | 按整行分页；`.awproject` 版本仍是 1；重开窗口恢复上次界面，不自动连接或运行 | 用当前程序打开旧项目并写一页 |
| 全库汉字和英文符号 | 建议字体“HanziWriter 全库·英文符号”，9847 字形；缺字会报出，不会静默丢掉 | 符号、不同字号、小点和细笔的纸面可读性 |
| 多区域、续页、模板 | 纸上拖动画框；续页、每页、仅首页、仅末页；模板不含正文和字体 | 双区域长文、标题首页、落款末页的实际多页样本 |
| 区域画布编辑 | 拖动、缩放、缩放平移、标尺、网格、可选吸附、撤销重做、复制、调整顺序 | 窗口缩放后拖动仍对得上毫米；缩小装不下的框会恢复，不裁字 |
| 逐页换纸 | 显示页码和阶段；页完成要笔抬起且控制器空闲；确认换纸只载入下一页，仍要点开始 | 两页纸：暂停不换纸，停止、断连、报警不推进页码 |
| UTF-8 导入、标点与英文换行 | 严格按 UTF-8 读取；句末标点不单独顶到下一行；英文单词能放下就整词换行 | 纸上看一行中英混排 |
| 缺字报告和补充字库 | 报告到区域、行、列；补充包只叠加，不改写原字库 | 故意缺一个字，看报告，再补上后重开项目 |
| 区域独立字体 | 每个区域可以指定自己的字库；项目记录指纹，字库被改过就拒绝打开 | 两个区域用不同字库写一页 |
| 手写变化 | 0 到 0.35 mm，固定种子；越出纸张就拒绝，不裁切 | 同一内容同一种子写两次，笔迹应一致 |
| 进度、日志、检查点 | 显示发送进度、运行和暂停时间；检查点只在抬笔并空闲后推进；断线后位置未知，不自动续写 | 写完一页看检查点；中途拔线后不能接着写 |
| 任务互斥 | 书写、暂停、等待换纸时，点动和自定义运动命令被挡住；停止和查询仍可用 | 书写中点主界面点动，笔不应被点走 |
| 表格 | 生成空文字格子；勾选“格线写入笔迹”才把线写进路径 | 同一表格分别开、关格线各看一次预览 |
| 图片和 SVG | 走主界面原有导入，不进入写字分页；换纸任务进行中拒绝导入 | 导入一张图，确认它不占用写字页码 |
| 设置变更绑定 | 已经载入主界面的写字程序，设置一改就不能再开始；其它 G-code 不受影响 | 载入后改字号，开始应被拒绝 |
