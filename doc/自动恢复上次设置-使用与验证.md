# 自动恢复上次窗口设置

机器配置与校准窗口正常关闭时，会保存当前机器配置（包括尚未另存的编辑）、文字、字库路径、字号、字距、行距、速度覆盖、纸张与边距、换行与起笔选项、停靠选项与坐标、计算输入和当前标签页。再次打开窗口或重启应用时自动恢复；首次启动仍使用原来的初始值。

这是原始界面状态快照，因此未完成的数字输入、无效数字和空覆盖也能保留。显式“保存/打开写字项目”流程保持独立，仍要求有效的项目参数。

运行时存储：`%LOCALAPPDATA%\GRBL_Plotter\AutoWriter\last-machine-setup.json`。格式版本1，先写临时文件并刷新，再原子替换，保留 `.bak`。损坏时尝试备份，并在窗口底部显示恢复结果；无法恢复时仍正常打开初始窗口。字库丢失时保留原字库路径和选择，显示提示，生成仍需字库可用或手动重新选择。

自动恢复仅恢复窗口编辑内容和报告，不连接设备、不写控制板或主界面工艺、不改变原点、不自动生成或载入程序。预览在重新打开时为空，需手动生成。

人工验收：关闭旧程序并打开新版，加载机器配置、选字体、输入文字和速度，然后关闭“机器配置与校准”窗口再打开；确认相同设置恢复。关闭整个应用再启动后再确认一次。第一次使用新版需先设置一次；旧版尚未记录的窗口内容无法从旧进程自动迁移。
