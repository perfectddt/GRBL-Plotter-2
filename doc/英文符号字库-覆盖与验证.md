# 英文符号写字字库

选择 **HanziWriter 全库·英文符号**（`hanziwriter-full-symbols.fontpack.json`）。原有字体文件未修改，旧项目仍使用原来字库。

共 9847 个字形，保留 9574 个汉字的原有笔迹与参数，补充实际书写的单线英文和符号。

## 覆盖范围

- 可打印 ASCII 全部 94 个字符：英文大小写 52 个、数字 10 个、全部键盘符号，包括 `* - [ ] { } ( ) / \ | ~ _ ^ @ # $ % & + = < >` 和引号、反引号。
- 全角 ASCII U+FF01–U+FF5E 全部 94 个，固定 12mm 字格，居中而不拉宽字形。
- 常用中文标点：`，。！？、；：“”‘’《》〈〉「」『』【】〔〕〖〗`，以及原有括号、破折号、省略号。
- 数学与单位：`± × ÷ ≠ ≤ ≥ ≈ ∞ √ ° ℃ ‰`，减号与常见横线变体。
- 货币：`¥ ￥ $ € £ ¢`。
- 方向与记号：`← ↑ → ↓ ↔ ↕ • ○ ● □ ■ ☆ ★ ✓ ✔ ✕`。
- 圈号：`①` 到 `⑳`。
- 空格仍由排版服务负责空移，不产生落笔；换行仍由排版服务处理。

英文小写具有独立的字形和较低字高；g/j/p/q/y 有下伸部分。I/l/1、O/0 有不同笔迹，其中数字0有斜线。符号是原创几何单线，不声称使用人类笔顺；实心符号通过内圈或短线表现，不是填充刀路。

并非整个 Unicode。emoji、生僻数学字符、其他语言文字和少见组合音标不在本次覆盖范围，缺字仍明确报错。精确补充清单在字库 JSON 的 `supplementalSymbols`，不得把未知字符静默替换为其他字符。

## 生成和验证

`scripts/generate-symbol-writing-font.py` 从紧凑汉字库派生独立文件；原创补充几何适用 `LICENSE-autowriter-symbols.txt` 的 CC0-1.0。HanziWriter 原有授权仍保留。

`scripts/test-symbol-writing-font.py` 验证全 ASCII/全角覆盖、9574 汉字完全一致、大小写区别、有限坐标、有效笔划及确定性生成；并输出真实字形笔迹图 `artifacts/symbols/font-contact-sheet.png`。

建议预览和纸面测试：

```text
Hello, World! [A-Z] * 2 - 1 = 3;
0123456789 I l 1 O 0 a g j p q y
¥100 ±5% → OK / ℃ ①②③
```

本次离线验证不代表纸面质量已验收。
