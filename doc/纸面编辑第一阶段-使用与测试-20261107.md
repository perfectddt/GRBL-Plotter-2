# 纸面编辑第一阶段

更新：第二阶段已增加局部橡皮擦、套索和正文预留区，见 [第二阶段说明](纸面编辑第二阶段-使用与测试-20261107.md)。本页保留第一阶段行为说明；当前版本支持包含预留区的版本 3 项目。

程序入口：`artifacts/autowriter/Release/GRBL-Plotter.exe`。

## 入口与使用

打开“写字配置 → 应用与写字预览”或“区域排版”，找到“纸面编辑”卡片，点击“编辑纸面（绘画／批注）”。需开启自动分页，但编辑纸面本身不需要连接机器或填写笔控速度。正在书写或换纸任务进行中不能打开编辑器。

独立窗口中，灰色为正文参考，红色为新增对象。编辑的是整体旋转之前的纸面毫米坐标；应用后，正文和对象一起经过最终旋转及机器方向映射。

工具直接显示：选择、画笔、直线、矩形、圆、箭头、文字批注。圆工具拖出圆或椭圆。画笔按下到松开是一笔，不会把不同笔连成一条落笔路径。

- 滚轮缩放，右键拖动画布；“适应纸面”恢复整页。
- 用页码切换对象所属的纸面。新增对象只属于当前页。
- 选“选择”后点击对象或其包围框范围，拖动移动；拖选框右下角蓝色方块缩放。
- 选中后“删除”移除整对象；撤销、重做按操作恢复，最多保留 50 步。
- 选“文字批注”，在纸上点击位置后输入文字。使用当前正文的笔画字库和毫米字号，缺字会报错。选中已有文字批注后点“修改批注”重新输入。
- “应用并关闭”提交，原预览失效；“取消”丢弃本次窗口内的修改。

对象移出纸面或缩放越界时恢复原对象；新绘制的越界对象不保留。长批注需要减小字号、换行或调整位置后再添加。

## 测试一：画图与批注

1. 准备一页短正文，启用自动分页。先将整体笔迹旋转设为 0，方便对照。
2. 打开纸面编辑，依次画一条自由线、矩形、圆和箭头，确认出现独立红色对象。
3. 选“文字批注”，在空白处写“工王一”；当前字库包含这些字。选中后“修改批注”，改成“王工”。
4. 用“选择”移动矩形，拖右下角缩放。滚轮放大、右键平移后继续操作，确认不会因显示比例改变实际毫米尺寸。
5. 删除圆，撤销后应恢复，重做后应消失。
6. 点击“应用并关闭”，再打开编辑器，确认对象、文字和位置仍在。
7. 再任意画一条线，点击“取消”，重新打开，这条线不应存在。

## 测试二：保存与恢复

1. 点击“保存项目”，另存为测试用 `.awproject`。
2. 新建项目后再打开该测试项目，确认正文和所有对象一起恢复。
3. 上次窗口状态也会记录对象，但正式保留成果应使用“保存项目”。
4. 带绘画的项目内部版本为 2，扩展名仍是 `.awproject`。新版可打开旧版本 1 项目；老程序会拒绝版本 2，避免静默丢弃绘画。没有绘画的项目仍可保存为版本 1。

## 测试三：验证新增、删除进入输出

1. 应用编辑后，点“生成并载入主界面预览”，正文和新增图形应同时出现。此操作需要已有完整机器参数，但不会自动开始书写。
2. 导出 PDF，不需要连接机器。PDF 中正文和图形位置应一致，文字批注可提取。
3. 回纸面编辑删除一条图形，应用后重新生成、重新导出 PDF。这条图形应在两处都消失。
4. 导出G代码并检查轨迹模拟，新增线条应有独立抬落笔动作；删除后不应仍有该条轨迹。

第一阶段默认先输出正文，再按创建顺序输出该页的新增对象。画面中的参考灰色不代表正文不书写；最终所有内容使用现有笔控输出，并非自动更换不同颜色的笔。

## 测试四：分页归属

1. 使用 29 行正文、每页 28 行，准备两页。
2. 在编辑器第 1 页画矩形，第 2 页画圆，应用后分别查看两页预览或导出 PDF，确认对象不会串页。
3. 修改正文使它只剩一页，再生成时应提示第 2 页仍有绘画，不得静默删除。
4. 重新打开纸面编辑器，页码仍能选到残留对象所在的第 2 页；删除该页对象并应用后，可以继续生成。

## 当前边界

正文通过原文本框修改；画布内可编辑的是新增手绘、图形和文字批注。已有正文尚未拆成可单独选择的字或文字框。第一阶段的删除为整对象删除，不含局部橡皮擦、套索、字形节点编辑。绘画固定在本页，不跟随正文重排，也不自动为正文让位；需要留白时使用区域布局或正文空行。删除对象只影响后续重新生成的程序，不能擦掉纸上已经写出的墨迹。

已有截图/G代码不做反向识字。新增手绘直接按毫米轨迹生成G代码，不依赖 OCR。

离线检查包括：绘画工具路径、移动、缩放、按页归属、删除与撤销重做、取消隔离、G代码生成、PDF路径增删、版本与项目坐标保存恢复。真实笔迹和机器方向仍需按本机既有验证流程做纸面验收。
