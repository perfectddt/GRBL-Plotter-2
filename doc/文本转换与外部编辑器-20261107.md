# 文本转换与外部编辑器

位置：“写字配置 → 应用与写字预览 → 内容与字体”，正文文本框下方。

布局遵循已约定的界面规则：文本转换独占整行；编辑器按钮采用两列等宽网格，奇数项的最后一项铺满一行；配置与载入修改组成同一行。按钮铺满卡片宽度，使用统一高度、字体和基线，不使用按文字宽度的自由换行布局，也不通过“更多”隐藏按钮。

## 从文本创建G代码

点击“从文本创建G代码”，打开原有文字转换窗口，并带入正文全部文字。已经打开过也可以重复点击，窗口会重新带入当前正文。打开窗口不会自动点击“创建代码”，也不会发送给机器。

此窗口使用原有 Hershey/系统字体转换流程，与 AutoWriter 的笔画字库和分页流程各自独立。只查看 28 行分页时仍使用原来的生成并载入预览，不需要打开文字转换窗口。实际书写或多页任务进行中禁止打开此转换入口。

## 外部打开文本

初始按钮为“用VS Code打开”“用Neovim打开”“用记事本打开”。需要本机安装对应程序。

点击“配置外部编辑器”：

1. 每行配置一个按钮，显示名称就是按钮中的程序名称。
2. 程序路径填可执行文件的完整路径，或 PATH 中的程序名。路径本身不要加引号。
3. 可用“选择程序…”选中安装位置。选中现有行再选择程序会修改该行；在空白新行选择会新增一项。
4. 启动参数中使用 `{file}`，程序会自动替换为带引号的正文文件路径；不写占位符时会在末尾追加文件路径。
5. VS Code 可以用 `Code.exe` 或 `code.cmd`，参数如 `--reuse-window {file}`；Neovim 用 `nvim.exe`，参数 `{file}`；记事本用 `notepad.exe`，参数 `{file}`。
6. 在表格底部新增行可以增加其他编辑器，选中整行按 Delete 可删除。点击“保存”后按钮立即刷新。

编辑器配置保存在 `%LOCALAPPDATA%\GRBL_Plotter\AutoWriter\external-editors.json`，重启后保留。编辑器尚未安装或路径不正确时，按钮会提示重新选择程序，不会安装软件。

## 将外部修改带回来

点击编辑器按钮会把当前正文写成一个独立 UTF-8 临时文件，再打开它。请在外部编辑器中保存为 UTF-8，然后回到软件点击“载入外部修改”。它会同步最近一次通过按钮打开的文件。

如果软件内正文也有改动，会确认是否使用外部文本覆盖。载入后原预览失效，需要重新生成。关闭写字设置后不保留这次临时文件的关联；再次编辑时重新点击外部编辑器按钮即可。

## 验证

- 正文里已有文字时，连续两次打开“从文本创建G代码”，两次都应显示当前文字，不需要重新粘贴。
- 修改编辑器显示名称并保存，确认按钮随之改变，重启后仍保留。
- 使用记事本打开正文，修改并保存，再“载入外部修改”，确认正文更新。
- 软件内和外部都修改时，取消替换应保留软件内正文。
- 程序路径不存在时应提示错误；带空格的正文文件路径应作为一个参数传递。

专项测试新增了重复打开入口、文件参数引用、无占位符时追加文件路径、外部修改载入与预览失效的检查；整体专项检查共 31 项通过，设置页布局回归通过。外部编辑器实际启动需按本机安装路径验收。
