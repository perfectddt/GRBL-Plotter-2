# 纸面编辑第三阶段

后续更新：已补充当前行原位插字/删字和批注独立字库、字号、字距、行距，见 [原位改字与批注属性](原位改字与批注属性-20261108.md)。

程序：`artifacts/autowriter/Release/GRBL-Plotter.exe`。关闭旧实例后启动新版，进入“写字配置 → 纸面编辑”。

## 1. 明确的移动工具

工具栏第二个工具是“移动”。套索圈住对象后会自动切换到它。此时可以从整个组合框内部（包括两个对象之间的空白）按住左键拖动，整组对象一起移动，不需要准确点中某条细线。点击组合框右下角可缩放。删除、撤销和重做仍按成组选中操作。

测试：画两个分开的矩形，用套索完全圈住两者，确认“移动”高亮。从两者之间的空白处往下拖动，两者应一起向下。删除后撤销一次，应同时恢复。

## 2. 不退出窗口修改正文

点击“编辑正文”，右侧出现全文输入栏，应用后更新排版。新版选择“正文改字”点击灰字，或在选择/移动工具下双击正文，则在当前行位置打开输入框，应用后直接重排。

正文变化和对象一起进入撤销/重做。只有点击整个窗口的“应用并关闭”后，才把正文和对象写回项目；点击“取消”不改变原项目。直接关闭窗口也不提交。

测试：

1. 准备一段两页正文，打开纸面编辑。
2. 在右侧正文中插入两行，点“应用正文并重排”，观察排版和页数。
3. 撤销一次，正文与对象位置一起恢复；重做一次，再次应用。
4. 点“应用并关闭”，原文本框也应显示新正文。
5. 再打开编辑器修改正文并重排，但这次点“取消”，原项目正文应保持上一次已提交的内容。

这是同窗口的文字编辑与重排，并非直接在笔迹线上显示 Word 式插入光标。正文仍保留文字身份；绘画、节点编辑各自独立。

多区域的正文继续通过区域编辑器修改；本次新增的正文侧栏、正文绑定和图形环绕首先适用于普通正文。

## 3. 批注跟随正文

选中一个批注、箭头或绘画对象，把它放在要关联的文字附近，点击“跟随文字”。软件会绑定本页距离对象左上角最近的正文字位，图上出现“跟随正文”标记。此标记只用于编辑，不书写。

修改正文、字号或行宽后，绑定对象会保持相对该字位的偏移，必要时跟随到下一页。“固定页位置”解除绑定。

测试：

1. 把一个箭头放在第一页靠下的一行文字旁，选中并点“跟随文字”。
2. 在正文开头插入几行，应用正文。箭头应跟着原文字向后移动；跨页时切换页码查看。
3. 撤销/重做，文字和箭头应一起恢复/移动。
4. 保存项目并重新打开，绑定应保留。
5. 删除被绑定的文字时，软件应提示先解除绑定，不能静默关联到另一句话。选中对象点“固定页位置”后再应用正文。

绑定使用文字位置与编辑范围追踪。单次修改跨度很大、涉及删除绑定范围时会拒绝应用，需先解除相关绑定或分次修改；同长度替换保留对应位置。它不是自动理解句子含义的语义批注。

## 4. 图形环绕与跨页重排

选中矩形、图形或手绘对象，点击“文字环绕”，再点“更新正文排版”。正文会避开对象包围框及约 1 mm 间隙。

每行选择可用空间较宽的一侧排字；两侧都太窄时转到图下方。不是同一行同时分两栏绕排。空间不足时正文继续到下一页。再次点击“文字环绕”关闭该对象的环绕属性。

测试：在页面左上画一个约占页面三分之一宽度的矩形，启用文字环绕。其右侧应有正文，图形下面应恢复整行排字。增加正文后，应自动分页，且无文字路径穿过矩形。

环绕插图固定在页面，不同时绑定正文，避免图的位置与正文排版形成循环。整行让位仍用第二阶段的“预留绘图区”。环绕对象是当前绘画模型中的图形，暂不等同于 Word 的任意嵌入图片。

## 5. 文字批注转为笔画、编辑节点

选中文字批注，点“转为笔画”，随后可在“编辑节点”工具中拖动蓝色节点。“删除”在此工具下删除选中的节点；路径只剩两个点时删除节点会移除该条路径。

转为笔画后，这个对象不再支持“修改批注”的改字功能，需要改字可撤销转换，或删除后重新创建文字批注。未转换的正文不能用节点工具直接改字，正文请使用右侧编辑栏。

测试：创建“工”字批注，转为笔画，选“编辑节点”，拖一个节点。该笔画应随之改变；撤销可恢复。对普通矩形也可以选择节点、拖动或删除。重新生成预览与PDF，改后的路径应一致。

## 保存与兼容

包含正文绑定或图形环绕的项目内部版本为 4，后缀仍为 `.awproject`。新版支持版本 1～4，旧程序会拒绝版本 4，防止丢掉绑定或环绕语义。当前页固定的普通绘画及预留区仍按已有版本规则保存。
