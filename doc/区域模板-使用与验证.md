# 区域模板复用

在“区域排版”点击“区域模板”。填写名称后“保存当前布局”，无需填写文字、验证机器或设置速度。左侧选择模板可查看纸张和区域框；可重命名、另存副本，导入/导出 `.awtemplate`。

模板包含纸张尺寸、四边边距、区域框位置和大小、内边距、字号、字距、行间隙、对齐、分页方式。不含文字、字体文件、机器配置、速度、原点和生成代码。应用后沿用当前字体和机器配置，需重新生成预览。

“保留现有区域文字”默认勾选，按区域编号对应。模板区域多时新增空区域，旧区域多时多余区域保留，避免丢失文字。若多余区域超出新的纸张范围，拒绝应用，当前布局不变。取消勾选会清空文字，应用时有明确确认；完整文本仍建议保存在写字项目中。

本地模板在 `%LOCALAPPDATA%\GRBL_Plotter\AutoWriter\RegionTemplates`。文件采用随机稳定编号命名，重命名不改变编号；覆盖保存生成 `.bak` 备份。不支持的版本或损坏文件显示读取错误，其他模板仍可使用。

验收：画标题、正文、落款三个区域，设置分页方式并保存模板。改变布局后应用模板，确认框恢复、文字按编号保留、页码回1、旧预览清空。新建项目应用同一模板，只应得到空框；填写新内容后重新生成。导出、导入应得到独立副本，机器设置及字体不变。
