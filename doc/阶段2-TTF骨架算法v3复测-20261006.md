# B 路线骨架算法 v3 改良（2026-10-06）

用户反馈 v2 仍有大量回笔。本轮更换骨架图构建与路径追踪，不改变字体来源、机器方向或 A 路线。新版默认723字B包和独立v3纸面样本已生成，尚未发送实机。

## 根因与修改

旧8邻接图在正交拐角、阶梯和交叉处添加多余对角边，形成像素级三角环；交叉簇BFS又重复走已追踪的图边，最后简化仍留下大量折返。v2只修缝合方向，无法消除图本身的多余环。

v3构图仅在不存在正交替代邻居时保留对角边，保留真正斜线；拆成链后固定配对端口，每条无向图边只遍历一次，取消重复BFS桥接。真实闭环单独保留，不能再与别的路径缝合；缺口缝合收紧到6px并要求向前。闭运算补中心并使用零填充边界，避免np.roll绕到另一边。仅剪除不超过3px的附着毛刺，保留交叉点、短独立笔及单像素点；不再在追踪后按8px长度一概丢线。单像素点生成0.5px短段以便笔式设备绘制。
