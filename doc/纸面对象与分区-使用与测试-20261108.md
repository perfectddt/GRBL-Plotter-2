# 纸面对象、历史、图层与分区

使用新版 `artifacts/autowriter/Release/GRBL-Plotter.exe`，关闭旧实例后重新打开。入口为「写字配置 → 纸面编辑 → 编辑纸面」。

## 正文：先选中，再改字或移动

1. 在「选择」「移动」或「正文改字」工具下，单击一个灰色字。该字的字框显示蓝色边框，对应的就是本次操作对象。
2. 已经单击选中后，再双击这个字，弹出原位输入框。直接对未选中的字双击只会选中，不会弹窗。
3. 输入框中是选中的字，不再默认带入整行。Enter 或「应用改字」确认，Esc 取消，Shift+Enter 插入换行。全文修改仍可用工具栏「编辑正文」按钮。
4. 拖动蓝框，把这个字移到新位置：它变成独立文字对象，原文中的字替换为实际空格，并记录原字宽。后面的正文不会因为这个空格比汉字窄而向前挤。
5. 独立文字使用文字批注的字体属性，可以修改字库、字号、字距和行距；不会重新写回原文框。删除独立文字后，原空位仍保留。撤销拖动可以恢复原正文。
6. Ctrl 单击可多选正文或绘画对象。多选不连续正文时，拖动会分别独立；双击改字只编辑点击的那个字，避免改到中间未选中的文字。

正文是源文本排版，仍需保留原文的项目；导入的纯 G 代码不会自动识别成文字。正文整页锁定后，原位改字、拖字和全文应用都会受到锁定限制。

## 对象、图层、分组

右侧「对象 / 图层」按当前页显示正文、图层、分组、分区和绘画对象。展开正文可按原文位置选择某个字。点击树中对象，可在纸面看到蓝框。

- 新建图层：成为后续绘制的当前图层。点击已有图层可切换绘制图层。
- Ctrl 多选对象或套索多个对象后，点「编组」。之后拖动、删除、显隐或锁定可对整组操作。「解组」保留组内对象。
- 「选择成员」选中容器的成员，方便进一步编组或修改归属。
- 「移入图层」「移入分区」打开目标选择框，不会自动改变对象位置；不满足目标分区边界时拒绝迁移。
- 「脱离容器」解除选中对象的图层、分区、分组归属，回到默认纸面。
- 「重命名」方便区分多个路径对象、图层、组和分区。
- 「上移一层 / 下移一层」改变叠放顺序，也改变这些绘画对象写入程序的顺序，不改变 XY 坐标。

隐藏内容不显示，也不加入生成的笔迹、PDF 或 G 代码。锁定内容继续显示并输出，但不能拖动、删除、改字或编辑节点。图层、分组、分区的显隐与锁定向成员继承；祖先锁定或隐藏时，单独解锁/显示子对象不能绕过祖先状态。

可在树中选中隐藏或锁定的对象，再点对应按钮恢复。对选中的灰色正文字单独执行隐藏/锁定，会先转成独立文字对象并在原文留空位；正文节点上的按钮则控制本页整段源正文。

## 历史记录

右侧「历史」显示本次打开纸面编辑器后的操作，保留最近 50 步。双击某条历史项回到该步；也可用撤销、重做或 Ctrl+Z / Ctrl+Y。历史中同时恢复源正文、绘画对象及显隐/锁定等属性。

历史用于本次编辑，关闭窗口后不保存历史栈；项目保存最终正文、占位信息、对象及容器关系。应用整个编辑器前，主项目不发生提交；取消整个编辑器会放弃本次修改。

## 工具栏与标尺

上排为绘画工具，图标对应选择、移动、正文改字、画笔、直线、矩形、圆、箭头、文字批注、节点、套索、橡皮擦、预留绘图区与页面分区。下排为文档操作。每个图标悬停会显示中文功能说明；「应用并关闭」保留文字主按钮。

「XY」图标显示/隐藏横纵标尺，单位毫米；标尺跟随缩放与平移，原点为纸张左上角。「整页」图标退出分区编辑范围。

## 页面分区

1. 悬停找到「页面分区」工具，在纸面拖出矩形。分区虚线与名称只是编辑辅助，不生成边框笔迹。
2. 在对象树选择分区，点「进入分区」；或用选择工具双击分区。底部范围显示当前分区名称。
3. 在分区内使用文字批注、画笔、直线、矩形、圆、节点、套索、移动、分组等工具。新对象自动归属该分区。
4. 分区外不能开始绘制；所属对象若拖动或缩放越过边界，操作恢复，不会静默裁掉笔迹。
5. 选择分区本身可以移动分区及其成员。分区整体可显隐、锁定、排序、重命名；点「整页」或「退出分区」恢复整张纸操作。

分区是同一页内的编辑范围与对象容器，不是新的分页文档，也不替代原「区域排版」中的独立正文框。原「预留绘图区」仍是让正文跳过整行的排版功能；分区本身不会让正文自动避让，需要时给具体插图开启文字环绕。

## 建议验收

1. 正文填两行「工王」「王工」。单击第一字确认蓝框，先直接双击其他未选中字确认不弹窗；单击选中后再次双击，改一个字，确认其他字不变。
2. 把第一字拖到空白处，检查原文框留下空格、第二字的 X 位置不变。双击新独立文字更改字号；删除后原文仍有空位；撤销恢复。
3. 画两条线，Ctrl 多选后编组，拖动、隐藏、显示、锁定后尝试删除，再解锁、解组。
4. 新建图层，在其中画图；隐藏图层检查成员一起消失，锁定图层后尝试移动成员。恢复后生成程序确认隐藏状态对应的内容不输出。
5. 建立分区并进入，在区内添加批注/图形，尝试将所属对象拖出分区。退出后整体移动分区，确认成员一起移动。
6. 切换 XY 标尺、改变缩放与平移；悬停每个图标检查功能说明。
7. 在历史中双击前一步，再回到当前状态；保存 `.awproject` 并重新打开，核对图层、组、分区、显隐、锁定和正文空位。

项目内部格式升级为版本 6，新版兼容旧项目，旧程序不支持新版场景属性。专项检查脚本为 `scripts/test-paper-scene.ps1`，截图位于 `artifacts/paper-scene/paper-scene.png`。
