## 4. 用户已确定的交互约定

1. 配置窗口打开时仍可操作主界面。
2. 先设整页，再直接拖动画框；自动编号，双击编辑数字和文本。不要替换成左侧区域列表工作流。
3. 区域预览显示框和编号，实际只写正文；框线不作为机器路径。
4. 多页复用相同区域位置，正文自动接到下一页相同区域。标题/页眉/落款用分页方式控制。
5. 打开默认恢复上次设置；切页或改参数后必须使旧生成代码失效。
6. 用户希望英文与常用键盘符号完整。可打印ASCII、全角字符、常用数学/货币/箭头/圈号已覆盖；未知字符应明确报告，不能静默丢字。

## 5. 后续任务顺序与验收

### P0：逐页换纸引导与任务状态联动（下一项）

**目标**：界面明确显示“第几页/总页数、等待开始、书写中、暂停、等待换纸、全部完成、取消或异常”，减少用户反复切窗口和误写页。

实现顺序：

1. 新增薄的多页任务状态服务；记录冻结项目/页面摘要、当前页、已完成页和当前载入页。
2. 接入现有主界面串流事件与控制器状态，识别开始、暂停、恢复、停止、错误、断连、正常结束。
3. **页完成必须区分发送完、收到应答与控制器真正空闲**。核对所有数据已确认、收尾抬笔、有效连接和 Idle 屏障，再进入等待换纸；不能把100%或最后一个 `ok` 当作物理完成。
4. 显示“已换纸并确认位置”按钮；确认后只准备下一页，首次版本仍由用户明确点击开始，不自动设置零点、不自动走定位动作。
5. 文本、布局、字体、纸张、机器映射或原点变化使冻结任务失效；不能继续使用旧页码对应的代码。
6. 取消/报警/断连不推进页码、不宣称完成；已发送但运动结果未知时显示未知，要求人工处理。

验收：至少两页；第一页正常完成后仅等待换纸；暂停不进入换纸；停止/断连/报警不进入完成；确认换纸前不能通过新任务入口启动下一页；重复点击不重复载入或发送。实机分别验收，记录实际与预期。

接入位置：`GUI/MainFormStreaming.cs`、`GUI/MainForm.cs`、`MachineControl/ControlSerialFormStreaming.cs`、`AutoWriter/MachineSetupForm.cs`。复用唯一串口发送器，不另建发送通道。主界面保留通用任务能力，新增互斥只约束已绑定的写字多页任务。

### P1：区域画布编辑体验

- 鼠标拖动移动和角/边缩放；保持毫米坐标，边界约束，数值与画布一致。
- 页面缩放、平移、标尺、网格及可选吸附；缩放不改变物理尺寸。
- 撤销/重做；复制时合理偏移；区域重排书写顺序和编号明确。
- 预览所选页的区域有效性、重叠与缺字位置；静态框与实际写入内容区分。
- 模板套用的编号对应关系更直观，后续可引入稳定区域ID/名称，避免删除重排后文字套错框。

验收：缩放/窗口尺寸变化后拖动仍定位正确；撤销恢复文字与布局；任何编辑使旧代码失效；不能通过缩小框静默裁剪正文。

### P1：可靠性专项与两页纸面验收

- 新英文符号的纸面可读性、不同字号、小点/标点和细笔效果；全汉字视觉质量不能由离线覆盖率替代。
- 双区域长正文、标题首页、落款末页的实际多页样本；检查顺序、漏写/重写与工作原点一致性。
- 断连、报警、命令错误、快速连点、结束后误恢复；核对普通模式与严格写字模式边界。
- 检查当前主界面已载入代码与设置窗口变更之间的提示和绑定，不能只清设置窗口代码就认定旧主界面任务不可用。
- 更换字号/算法后的回归样本冻结；现有字库包不要原地覆盖造成已保存项目失效。

### P2：文字输入与字体体验

- UTF-8纯文本文件导入；标点禁则（句末标点不单独顶到下一行），英文单词换行规则。
- 全文缺字定位到页/区域/原字符位置；覆盖报告与用户指定字符补包。
- 区域独立字体、字体预览/选择/本地管理。增加字体引用后项目版本兼容和指纹策略必须同时设计。
- 可选有界、固定种子的手写变化；保存后重开结果一致，最终路径再次检查越界。

### P2：进度、诊断及恢复

- 当前页/区域进度、预计耗时、实际运行/暂停时间；发送进度与已完成字数区分。
- 任务日志关联页/区域/字符/笔画；先诊断，再做保守检查点恢复。
- 断线后位置未知，不能自动续写；只有抬笔、排空并确认Idle的边界才能推进可靠检查点。
- 单步及自定义命令按任务互斥接入；不绕过唯一发送器。

### P3：表格格子、图像输入与交付

- 表格/格子模板，文字与格线是否实际画出独立配置；图片/SVG等输入先核对底座已有能力再复用。
- 统一发布目录、版本标识、启动入口、迁移和备份说明，结束当前不断增加阶段EXE的开发交付方式。
- 审查后分批提交现有工作。用户截图改动与代码分开核对；提交/推送需用户明确授权。
- PDF、联网字体、云同步、关机等不纳入当前下一项，待目标确认后单独设计。

- 现用配置：`artifacts/stage1/machine-profile-continuous-pen-confirmed.json`。模式Z，抬笔0、落笔5、连续运动要求；`xDirection=1`、`yDirection=-1`、工作坐标G54。配置整体仍是Unverified，局部事实已确认，不自动升级为全机器认证。
- 之前字体样本显式速度：绘图1000、空移1800、Z速10000 mm/min。文件可能未保存速度，生成时需配置或明确覆盖；不静默给未知参数补默认。
- 纸张左上角对应工作原点约定；界面默认上下翻转。保持厂商方向，不为了显示修改控制板轴方向。
- 载入不等于发送；不自动回零、复位、解除报警或设置原点。`$X`不等于清空planner。
- 汉字数据来源与许可、原创符号许可分别保留。原厂加密gfont不破解；本机Windows字体衍生B包不当作可分发资源。
- fontpack `glyphs`为条目数组，不能改成字典对象；旧解析器环境已发现字典静默为空的问题。
- `advanceMm`只改占位，不能以此拉伸笔迹。点号仍需有效折线，不能输出无运动驻留或伪造笔画。
- 删除实际文件遵守回收站约定，不永久删除。模板删除功能尚未实现。

## 8. 验证记录与后续检查方式

本轮已有通过记录：区域续页69项核心/17项实际窗口，模板18项核心及实际模板保存应用测试；普通分页95项，项目34项，界面27项，设置恢复25项。早期282项写字控制和144项锚点是既有记录，不宣称本次全部重跑。各阶段都构建过Debug/Release，但实际纸面验收范围见第3节。

常用命令（Windows PowerShell/.NET Framework环境）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -SkipRestore
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-regions.ps1 -ApplicationPath 'D:\yy-code-git\autowriter\artifacts\templates\Release\GRBL-Plotter.exe'
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-stage2-page-project.ps1
python scripts/test-symbol-writing-font.py
```

`build.ps1`默认写原bin目录，遇到运行进程锁定时用VS2022 MSBuild指定独立 `OutDir`，Debug/Release顺序构建。部分历史UI脚本固定 `bin/Debug`，必须确认测的是当前程序集；不能拿旧EXE测试通过证明新版正确。模板测试为 `RegionTemplateTests.cs`、`RegionTemplateIntegrationTests.cs`，用.NET Framework csc编译；后者传入新EXE、独立状态文件路径和空模板目录。实际交互测试必须有退出/超时保障，不能留下测试对话框占用流程。

曾发现的关键复现：编辑框可把 `CR LF LF` 显示成两行，而直接排版变为三行，字号6时多6mm空白。用户截图没有可见空行；读取旧保存文件不能直接代表当前编辑框。现统一输入、恢复、保存、生成边界，保留真正CRLFCRLF/LFLF空行。不要再让用户删正常换行代替定位。
