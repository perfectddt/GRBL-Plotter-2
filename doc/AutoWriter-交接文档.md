## 2. 重大新证据：厂商暂停/停止的字节序列已嗅探到手（改变开发方向）

并行会话用 frida 被动嗅探原版奎享雕刻实机作业（`doc/阶段1-串口嗅探交接.md`、`doc/阶段1-实机嗅探结果-20261006.md`，日志 `artifacts/stage1/capture-live-20261006-full.log`），用户确认**暂停和停止都抬笔**：

| 动作 | 厂商实际发的字节 |
|---|---|
| 暂停 | `G1G90 Z0.0F10000`（抬笔，走运动队列），随后写入静默 |
| 恢复 | `G1G90 Z5.0F10000`（两次）+ 继续 XY |
| 停止 | `G1G90 Z0.0F10000` + `G90G0 X0Y0`（抬笔 + 回工作原点） |

**结论**：不存在神秘的"绕过 planner 实时抬笔入口"——厂商就是**纯软件序列**：停发新行（其流式窗口小所以停得快）→ 队列跑完 → Z0 抬笔 →（停止时）回原点。**没有 `!`、没有 `~`**。这验证了我们 N=4 限流方向正确，也给出了暂停抬笔/停止抬笔的直接抄作业路径：**暂停=笔画边界停发→抬笔；停止=停发→抬笔→回原点**（替代现在的 `!`+锁存方案，或与之组合）。固件协议公开资料仍为零（`1.3a.20221114` 全网无命中；34 项 `$` 恰好=标准 Grbl 1.1 全集，定制全在固件里）。

## 3. 能力地图（代码在哪）

- **写字生成链**：文本 → `TextLayoutService.Layout`（解析链：选中字库包 → 内置字形 → 大声报缺字）→ `WritingProgramService.Generate`（起笔对齐/收尾回位/连续笔控不变量）→ G-code。
- **字库**：`BuiltinGlyphLibrary`（工/王一示意字形 + `Knows`）；`GlyphFontPackService`（加载校验 + `ResolveWithFallback` + `ChainHasGlyph`）+ `GlyphFontPackCatalog`（四处目录发现）；`GlyphFontPack` 格式 schema v1——**glyphs 必须是条目数组**（见 §5 坑 1）。
- **字库生成脚本**：`scripts/generate-stage2-fontpack.py`（路线 A：hanzi-writer-data → pack，确定性输出，内嵌 723 常用字表，`--chars-file`/`--all`）；`generate-stage2-fontpack-ttf.py`（路线 B：栅格化 400px → 闭运算 → Zhang-Suen → 剪刺 → 骨架图交叉簇合并 → 端点缝合 → 启发式笔序；`--font` 可换字体）。
- **UI**：`MachineSetupForm` "应用与写字预览"页：字体下拉/文本/字距/行距/字号/起笔对齐/回位 → 生成预览 → 检查连续排队 → 导出 / **载入主界面预览**（载入不发送，主界面 ▶ 显式发送）。
- **暂停/停止**：`StreamThrottle`（N=4 未确认窗口）、`StopHoldGuard`（停止锁存，仅 GRBL 欢迎消息解除）、`StrokeBoundary`、`PauseMoveGuard`、`ResumeRestore`/rewind。**§2 的厂商序列是下一轮改造的输入**。
- **显示**：`ViewTransform`（默认上下翻转与纸面同向）、2D 预览、笔 Z 分类（`PenZClassifier`）。

## 5. 铁律与坑（违反=事故）

1. **不破解**奎享加密模块、不读许可/认证；`.gfont` 已弃用（厂商加密）。**版权**：方正/汉仪/华康字体文件（含 TTF）一律禁用；可用 = HanziWriter 数据（APL）、TW-Kai（政府开放授权）、思源（OFL）；**Windows 自带 simkai 的衍生字库包只进 artifacts 不入仓库**。
2. **笔控语义**：连续排队 Z0 抬/Z5 落 F10000；落笔后必须紧接 XY；禁 G4/驻留；`requiresContinuousPenMotion=true`。`ok` 只代表接收不代表运动完成。
3. **未知值不自动补默认**（配置 Unverified 就如实未验证）；**不静默丢**字/笔画/点。
4. **实机纪律**：每次运行重新核对原点与笔位；载入 ≠ 发送；不自动回零/复位/解锁；红色停止后锁存需复位欢迎消息解除、`$X` 不清 planner；行程以 R6 验证箱（X 0..41，Y ±20）为准，`$130-132` 不是实测行程；一次成功不外推全行程。
5. **文档纪律**：不夸大（目视通过 ≠ 精度验收；离线通过 ≠ 实机通过）；开发逐次记入 `doc/开发记录.md`。
6. **技术坑**：①fontpack 的 glyphs 用条目数组（本机 .NET DCJS 读 Dictionary 一律静默空）；②PS 5.1 按 GBK 读无 BOM .ps1，**行尾中文会吞换行**——.ps1 一律纯 ASCII、中文用码点、断言只配 ASCII 子串；③奎享雕刻启动后**必须点"选择机器"对话框的"确定选择"**才进主界面（自动化导出通道时必记）；④GitHub raw 直连被墙，用 npmmirror/阿里云镜像。
