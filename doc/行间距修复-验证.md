# 单页实际墨迹行间距修复

单页排版不再用固定 em 行步长。先确定自动换行的行内容，再测量每行实际笔画上下边界；下一行顶部与上一行底部的距离严格等于“行间空隙mm”。同一行所有字保留统一基线和原始笔画，标点不单独上移。首行实际墨迹顶部对齐上边距；空行或全空格行保留字号高度的空白区域，并叠加行间空隙。

旧式无纸张 Layout 行为不变。CRCRLF 归一化为一次换行，CRLF、CR 和 LF 同样支持；故意连续 LF 保留为空行。

真实紧凑字库两行样本“你好，世界！”和“今天开始测试写字，123。”在字号6/10、行间空隙0/2下，实际墨迹间隙分别精确为0/2mm。32项纸张/项目检查通过；Release输出位于 artifacts/line-gap-fix/Release。未实机验证。

注意：原实现固定步长仍额外包含字形的上下留白。该样本字号10，em12步长、设置0时实际空隙约1.852mm；若调用传入14则约3.852mm。截图使用的可执行文件与原始换行内容未取得，不能单凭截图断定具体是哪一项。
