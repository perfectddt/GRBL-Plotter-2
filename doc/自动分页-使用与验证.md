# 自动分页与手动换纸

2026-10-11：新增自动分页、当前页/总页数、上一页/下一页。

程序：`artifacts/pagination/Release/GRBL-Plotter.exe`。

勾选“自动分页”，设置纸张边距与字号，输入长文，点击“生成写字预览”计算全部页并只生成当前页。页码切换清空本窗口代码，需点击“生成并载入主界面预览”更新主界面。主界面此前载入的代码不会自动替换；执行前确认载入的是当前页。

每页保留纸张左上工作原点和边距。写完一页后手动换纸并确认相同工作原点，再选择下一页、生成并载入，手动开始。程序没有自动发送、自动翻页或自动换纸控制。

整行放不下时换页，单行自身超过可写高度或单字超过宽度时报错，不截断。按实际笔迹高度和行间空隙排版。空行（含首尾空行）保留字号高度，可能产生空白页；空白页无笔画，不可生成写字程序，跳过即可。纸张仍需适合机器工作范围。

项目 v1 新增可选 SelectedPage 字段，旧 v1 不含此字段时回到第一页；上次窗口设置也保存页码。参数变化清空分页缓存和本窗口预览，重新生成后越界页码自动缩到末页。

验证：95 项分页几何/顺序/数量/换行/边界/空行检查；34 项单页与项目检查（含旧 v1 迁移及页码往返）；27 项界面失效检查；分页真实窗口当前页选择、保存恢复、缓存失效检查；编辑框换行恢复及实际字库 0/2mm 间隙检查。Debug/Release 构建通过。未实机多页纸面验收。
