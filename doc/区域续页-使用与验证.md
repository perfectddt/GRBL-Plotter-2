# 区域续页

打开 `artifacts/region-pages/Release/GRBL-Plotter.exe`，在区域排版页勾选多区域排版。纸张、字体沿用应用与写字预览页设置。拖动画框，双击区域，编辑文字、尺寸、字号和分页方式。

- 自动续到下一页：正文在区域内部自动换行，满后续到下一张纸的同一位置；每段文字只写一次。旧项目与新建区域默认采用此方式。
- 每页重复：用于页眉、固定标题等，每页显示同样文字。
- 仅首页：例如文章标题。
- 仅末页：例如署名，显示在所有正文结束的最后一页。

总页数取所有自动续页区域的最大页数；较短区域结束后，其后各页不再写该区域文字。没有多页正文时，仍为一页。重复、首页、末页区域要求文字能装入单个框，超出时会报错；不自动缩小或截断。

点击区域笔迹预览计算页数，再用上一页、下一页或页码切换，重新预览或生成并载入主界面。每次只载入当前页；切页或修改参数会清空旧代码与区域笔迹预览。区域框作为每页模板保留显示，不生成任何框线书写指令。空框可以留作占位。保存项目会保存区域分页方式与选中页码。

换纸仍由用户手动完成；每页确认相同工作原点，手动开始书写。程序不会自动发送下一页或自动换纸。仅有空白行的页面可能没有可书写笔迹，此时生成会报错而不会以示例文字代替。

## 离线验证

核心检查覆盖独立区域续页、总页数、自动换行完整性、三种静态区域、静态溢出、非法分页方式、字形坐标与框线不进入代码、项目和窗口状态往返。生产界面检查覆盖画框、双击编辑、两处页码同步、页切换清空旧代码和笔迹、当前页选择以及重开恢复页码。未进行纸面实机验收。
