# 侧栏拖动与预览翻页

程序：`artifacts/autowriter/Release/GRBL-Plotter.exe`。

- “页面与分页”的“字高%”标签按实际渲染字体测量宽度，避免百分号被裁切。
- 左侧栏右边缘、右侧栏左边缘各有一条竖向分隔条。鼠标移上去变为左右调整光标，按住左键拖动即可调整宽度。中间区域随之变化。收起再展开会恢复本次调整的宽度；重启后回到默认宽度。
- 先在写字配置中生成并载入多页文字，再进入“预览”。预览顶部有“上一页、当前页/总页数、下一页”。翻页会重新生成并载入对应页，不会开始发送。首页/末页自动禁用越界按钮。
- 尚未生成分页、设置已改动、正在书写或多页任务进行中，预览翻页会禁用。多页任务换纸仍使用“已换纸并确认位置”，不会通过预览翻页推进实际任务。

测试建议：载入 29 行正文，设置每页 28 行；预览第一页应有 28 行，点击下一页仅剩 1 行，再点击上一页恢复。分别拖动两个侧栏边缘，并收起/展开，确认宽度恢复。

离线检查：27 项分页与 PDF 专项检查、设置页布局检查通过；包含字高百分号宽度和预览翻页载入代码的回归检查。实际鼠标拖动和窄窗口体验仍可按上述步骤验收。
