# 全库写字字体（2026-10-11）

字体名称：**HanziWriter 全库9574字·标点数字·宽度优化**。
文件：`GRBL-Plotter/AutoWriter/Fonts/hanziwriter-full-metrics.fontpack.json`。
重启新版程序，在“应用与写字预览”字体列表选择此项。
原有 `hanziwriter-full.fontpack.json` 和原字体名称保留，文件内容不变；旧项目及记住的字体选择继续使用原版，宽度优化需主动选择。

覆盖 9574 个汉字及 45 个补充符号，共 9619 个字形；空间沿用内置空移。
补充覆盖中文逗号、句号、顿号、分号、冒号、问叹号、弯引号、圆括号、方括号、书名号、破折号、省略号，以及 ASCII 数字和常用标点。英文字母、表情、全角数字不包含，缺字仍明确拒绝生成。
数字是简单七段单线造型，标点是原创单线几何，不声称来自真实笔顺。中文笔画来自本地 hanzi-writer-data 2.0.1 medians，保留 Arphic 许可；补充符号使用 CC0。

数字与 ASCII 标点现在按实际宽度前进：12mm 标准字格中，数字统一为 8mm（包括 1，便于数字对齐）；ASCII 标点为原笔画宽度加左右各 1mm 留白。中文标点保留惯用的 12mm 全角字格。字号会等比例缩放这些宽度，字距仍另加。例如字号 6mm 时数字字格为 4.8mm，汉字为 7.2mm。
笔画只做水平平移以放入较窄字格，不压缩或拉伸。空格仍为 6mm 标准步进，单页制表符仍报错并要求改为空格。自动换行按字形步进宽度计算。旧项目原字体和指纹保持有效；选择新“宽度优化”字体后重新生成、另存项目即可采用新版宽度，新排版结果可能与旧版不同。
字库 schemaVersion 仍为 1，可选的逐字 `advanceMm` 缺省时沿用 `advanceCjkMm`，旧字库继续使用。加载器拒绝非正值、非有限值、超过 48mm 的步进以及笔画越出明确指定字格的字形。

建议先生成：


这不是 TTF 外轮廓字体：一个源笔画对应一条中心线，机器可以按笔顺单线书写。
原有 723 字试点包不变，仍用于已验收样本的对照。新全库仅基线从 1.0mm 改为 1.1mm，统一平移所有中文点 0.1mm，以使源数据最低 y=-96 落入 0..12mm em。不裁切、不变形；完整中文范围 X=0.386..11.705mm、Y=0.009..11.157mm。
