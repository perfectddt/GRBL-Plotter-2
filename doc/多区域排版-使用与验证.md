# 多区域单页排版

本版保留普通文本自动分页，新增在同一张纸上绘制多个独立文字区域。机器配置与校准窗口现在为非模态窗口，打开时可以操作主界面；重复点击菜单会激活同一窗口，关闭主界面会关闭该窗口并保存设置。

## 使用

1. 在“应用与写字预览”设置纸张尺寸和共享字体。
2. 切换“区域排版”，勾选“多区域单页”。
3. 在纸张空白处按住鼠标左键拖动绘制矩形，松开后填写区域属性。小于 3mm 的拖动忽略。
4. 属性包含从纸张左上角量起的 X/Y、宽高、四边内边距、文字、字号、字距、笔迹行间空隙、每行左／中／右对齐。坐标单位均为 mm，Y 向纸张下方增加。
5. 点击已有矩形选中，双击重新编辑；也可复制或删除选中区域。编号按创建顺序书写，允许重叠但界面会提示。
6. 点击“区域笔迹预览”查看所有区域的文字笔迹。蓝色／橙色区域框和编号只显示在此纸张画布中，不进入 G-code，也不会在纸面画出。
7. 点击“生成并载入主界面预览”载入所有区域的文字路径；主界面仅显示实际生成路径。操作不会自动开始发送。

纸张外边距的虚线是参考；区域可放在纸张范围内任意位置，由各区域内边距控制文字位置。超出纸张的区域、放不下的文字和缺字会整次报错，不截断文本。空区域是占位，全部为空时拒绝生成。复制区域自动向右下偏移最多 3mm，无法偏移时可能与原区重叠。

保存／打开 `.awproject` 和关闭后自动恢复均保留区域内容和参数。关闭多区域模式后继续使用普通文本分页，区域设置仍保留。旧项目缺少区域字段时正常打开。

## 软件验证

`scripts/test-regions.ps1` 验证区域坐标、独立字号和间距、对齐、内边距、溢出、组合顺序、G-code 无区域框、项目兼容与往返、画布缩放／拖动／命中、属性窗口确认，以及实际设置窗口创建、双击修改、生成、关闭和恢复。

原单页／项目、分页、换行归一化、真实字库笔迹行间空隙、上次窗口设置恢复测试通过；Debug／Release 构建通过。尚未多区域实机纸面验收。
