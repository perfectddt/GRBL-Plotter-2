# 字距与字体菜单修复

新版入口：`artifacts/spacing-fix/Release/GRBL-Plotter.exe`。

字体菜单自动加宽；超长名称可通过底部横向滚动条查看，鼠标停在选中字体上也显示完整名称。

选择 **HanziWriter 全库·紧凑标点**，把 **行间空隙mm** 改成 **2**，生成并载入预览。旧设置中的4仍会恢复，需要手动改一次后关闭窗口保存。

单页排版行步长由 `14 × 字号/10 + 空隙` 改成 `12 × 字号/10 + 空隙`。12mm字格包含字体完整范围；字号10、空隙2时，两行起点间隔14mm。未启用单页排版的旧布局算法保持原样。

紧凑字体为独立文件，不改变原完整版和宽度优化版。15个中文标点仅横向平移并缩短占位；保留笔画大小、笔顺和基线。逗号占位由12mm改为2.7mm（字号10时），字距仍使用界面输入值。

检查：Debug/Release构建、27项UI检查（含原生水平滚动样式与内容范围）、27项页面/项目检查以及9619字形身份和15个标点几何保留检查通过。尚未实机纸面验收。
