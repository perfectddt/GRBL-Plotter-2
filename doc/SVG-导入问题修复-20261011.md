# SVG 与图片导入问题修复（2026-10-11）

## 修改

1. 主界面载入写字预览、设置或拖动黑色起点只修改预览标记。移除自动 G10 L20 P0 和直接改写 Grbl.posWork 的逻辑；真实工作坐标以控制器报告为准。标记不是运动命令，也不平移程序。
2. SVG 每个元素从祖先独立解析样式，不再将一个叶节点的颜色、填充、线宽传给兄弟节点。保留原始样式，重复解析不污染来源。
3. CSS 按重要性、选择器优先级和源码顺序解析；普通规则中的行内样式优先，重复规则后者生效。支持简单元素/class/id及!important；不支持的复合选择器忽略并记录警告，不误当全局规则。
4. AutoWriter 图片/SVG入口使用单次转换的不可变笔控上下文。转换期间覆盖生成器笔控值，不写设备档、不改工具表、不保存XML或user.config；取消、异常、正常结束均退出。图片窗口保存该文件上下文，延后生成时临时启用，后续普通导入清除旧上下文。

未知笔控方式或缺少必要数值现在明确报错，不再静默用旧设备档继续。主界面原有直接导入没有AutoWriter上下文时保持既有行为。图片灰度高度/像素功能自己的ZTop/ZBottom仍是独立参数，本次常规Z绘图转换不能代替这些模式的配置与验收。
