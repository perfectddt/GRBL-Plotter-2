# 纸面编辑第二阶段

更新：新版已增加独立移动工具、窗口内正文编辑、文字跟随、图形环绕和节点编辑，见 [第三阶段说明](纸面编辑第三阶段-使用与测试-20261108.md)。套索后会自动进入移动，可拖动组合框内空白。

使用 `artifacts/autowriter/Release/GRBL-Plotter.exe`。入口仍是“写字配置 → 纸面编辑 → 编辑纸面（绘画／批注）”。纸面编辑不要求连接机器；实际生成G代码仍需要既有机器参数。

新增“套索、橡皮擦、预留绘图区”工具和“更新正文排版”按钮。

## 1. 橡皮擦局部删线

1. 选“直线”，画一条较长横线。
2. 选“橡皮擦”，从横线中间竖着划过，线应断成两段，中间为空白。
3. 点击“撤销”，整次擦除应恢复；点“重做”，重新出现断口。
4. “应用并关闭”后，重新生成预览或导出PDF，断口应仍在。
5. 模拟/检查G代码轨迹，断口两侧应是独立的抬落笔动作，不能有落笔线穿过擦除区。

橡皮擦直径固定 4 mm，使用纸面毫米尺寸，放大显示不会改变实际擦除宽度。可以擦手绘线、直线、圆、矩形、箭头；不会擦灰色正文、文字批注或蓝色预留区。文字用原编辑器修改，文字批注用“修改批注”或整体删除，避免文字层与笔迹不一致。

## 2. 套索多选

1. 在同一页画两个矩形、一条线。
2. 选“套索”，按住左键圈住其中两个对象，松开后，两者应同时出现选框。只选中完全圈住的对象。
3. 切换“选择”，从已选对象上拖动，两者应一起移动。右下角蓝色方块可按组合包围框缩放。
4. 点“删除”，两个对象一起消失；撤销一次应一起恢复。
5. 未圈住的第三个对象应保持不变。

套索只选择本页新增对象，不直接选择正文字符。切换页码会清除选择，不会删掉对象。

## 3. 预留绘图区与自动排版

此功能先支持普通正文，不与多区域文字框自动环绕混用。先关闭“多区域排版”；多区域模式继续通过调整文字框留白。

1. 准备较长正文，开启自动分页，整体旋转先设为 0。
2. 打开纸面编辑，选“预留绘图区”，从希望留白的位置往下拖出所需高度。
3. 出现横贯纸张的蓝色辅助带。横向宽度自动使用整页，拖动决定垂直位置和高度。
4. 点击“更新正文排版”，灰色正文应避开该高度；装不下的正文会移到下一页。
5. 在蓝色区域里画图或加批注，点击“应用并关闭”。重新生成或导出PDF，正文应让位，绘画应存在，蓝色边框和提示文字不应被输出。
6. 选中蓝色预留区，可上下移动或用右下角调整高度。修改后再点“更新正文排版”。
7. 删除蓝色预留区，更新正文排版，正文应回填；区域里的绘画作为独立对象保留，需要时再一起删除。

按行数排版时行步距不变，预留区会占用整行位置，因此有绘图区的页面可能少于设置的最大行数。例如原本每页 28 行，空出两行高度后，实际正文可能只有 26 行。这不会把文字缩小或压进绘图区。

预留区属于固定页，第三阶段再增加跟随段落/文字的锚定。目前不支持左右两侧绕图排字，而是整行让位。

## 4. 修改正文后重新排版

1. 保留预留区并退出编辑器，在原文本框中增加几行文字，再生成预览。
2. 正文应重新分页并继续避开预留区，不丢字、不裁切。
3. 打开纸面编辑检查绘画仍在固定页的位置；它不会自动跟随某句话移动。
4. 若删掉大量文字，使某个绘画所在页不再存在，软件仍应提示处理该页对象，不会静默丢弃。

## 5. 保存与兼容

保存项目、重新打开后，擦断的路径、对象位置和预留区应保留。带预留区的项目内部版本升级为 3，扩展名仍是 `.awproject`；新版支持旧的版本 1/2。旧程序应拒绝版本 3，避免把辅助边框误当成书写路径。只有普通绘画时仍按第一阶段的版本 2 保存。

建议用“另存”的方式保留一份原项目，验收通过后再覆盖常用文件。
