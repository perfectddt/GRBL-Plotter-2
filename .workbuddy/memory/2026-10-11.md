## SVG 导入"线条乱"根因（已定位）
- 现象：导入自写 SVG 后闭合图形变实心/多出来回密线。
- 根因链：① `ParseAttributs()` 每次调用都把 `attributeStroke/attributeFill` 重置为 ""（`GCodeFromSvg.cs:713-714`），**只读当前元素自身**的属性；写在外层 `<g>` 上的属性子元素拿不到。② `<g fill="none">` 走的是 `element.Attribute("fill")` 分支（747-758），该分支只 `SetPenFill`、**不更新 `globalTextProp.fill`**（只有 `style` 分支 726-731 才更新）→ 等于 fill="none" 丢失。③ 默认设置 `importSVGApplyFill=True`（Settings.settings:1172）→ `HatchFill` 对**闭合且 ByFill 不是 none/空**的路径生成填充密线（`GraphicGenerateHatchFill.cs:114-124`）。
- 推论：方框/圆被填满 → "线条乱"；line/polyline 不闭合不受影响。
- 规避写法：**每个图元自带 `style="fill:none;stroke:#000000;stroke-width:0.5"`**（照 Inkscape 风格），或全部合并成单条 `<path>`。测试件：`artifacts/stage2/import-test-graphic-60x40-style.svg`、`-path.svg`（对比原始 `import-test-graphic-60x40.svg`）。
- 其他已确认：`stroke-width` 导入器根本不解析（732-736、759-764 被注释，全局仅 `SetPenWidth("1")`，`GCodeFromSvg.cs:525`）；默认 `importSVGMaxSize=100` 会把 >100mm 的 SVG 整体缩放；`importSVGCircleToDot` 开启时 `<circle>` 直接变一个点。

## 导入 SVG/图片「抬落笔全错」根因（已用真值+真实配置复现）
- 现象：导入的图形空移时压笔、画线时抬笔（用户报"什么时候按下去什么时候抬起来都是错的"）。
- 根因：**Z 约定相反**。GRBL-Plotter 的设备档是 CNC 语义（抬笔=SaveZ 高/正、落笔=FinalZ 低/负），本机是 **Z0=抬笔、Z5=落笔**。
- 链路：`guiToolSelection=2` → `DeviceSelection.Router`（MainForm.cs:234-238；`tC_RouterPlotterLaser` 页序 0=Laser/1=Plotter/2=Router）→ `MyControl.UseSpecificDevice()=true` → `OverideGcodeSetup()`（UserControl.cs:572-585）先设 `OptionZAxis.Up/Down = SaveZ/FinalZ`，随后每组 **`GetValuesFromToolList()`**（Graphic2GCodeRelated.cs:1821-1854、1886-1899）再次用**工具表**值覆盖 `OptionZAxis.Up=dtp.SaveZ / Down=dtp.FinalZ` —— 工具表最终说了算。
- 实际值（`GRBL-Plotter/bin/Debug/data/tools/_currentToolList.xml`）：`Router SaveZ=5 FinalZ=-1 FeedZ=100 FeedXY=200`；`Plotter SaveZ=2 FinalZ=-2`；`Laser SaveZ=5 FinalZ=0`。与设备页默认（Router ZUp=5/ZDown=-1）一致 —— 用户从未改过，是 GRBL-Plotter 出厂默认。
- 生成结果（Router 实测）：抬笔 `G00 Z5.000`、落笔 `G01 Z-1.000 F100` ⇒ 机器上正好反了。
- 对照：写字生成器 `WritingProgramService.cs:482-490` 用 profile 的 `G1 Z{penUp=0}/Z{penDown=5} F{zfeed}`；2D 预览 `ApplyPenPreview()`（MachineSetupForm.cs:1246-1257）只写 `gui2DPenZUp/DownValue=0/5`，**没有**同步到导入用的设备/工具表 Z 值 → 三条路不一致。
- 真值工具已升级：`scripts/test-svg-import.ps1 -Svg <f> -Device Router -ZUp 0 -ZDown 5 -ZFeed 10000`（harness 内用反射 `SetToolsProperties`+`SetSelectedDevice`；注意 `DeviceSelection/MyControl` 在 `GrblPlotter.UserControls` 命名空间，`ToolProperty` 在 `GrblPlotter`）。输出存档 `artifacts/stage2/pen-{laser,router-userconfig,router-machine}.txt`。
