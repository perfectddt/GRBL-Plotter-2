## 第五轮：对齐（"注意对齐啊"）
- **根因**：行内控件靠各自手写 `Margin.Top`/`Padding` 对齐，Label（AutoSize，文字顶对齐）与输入框（文字垂直居中）中心差 5px+，视觉上参差。
- **改法**：`UiTheme` 加统一尺寸常量 `ControlHeight=26 / RowHeight=28 / RowGap=4 / FieldGap=8 / LabelGap=4 / CardPad=10`；新增 `UiRow : Panel` **自己算位置**（OnLayout 里逐个摆放、超宽换行、`child.Top = (lineHeight - child.Height)/2` 垂直居中；`Dock != None` 的控件跳过，供 `AddWide` 整行填充）。`UiGroup` 改为聚合 `UiRow`，提供 `Add/AddLabel/AddField/AddButton/AddCheck/AddWide/Note`。
- **Label 必须 `AutoSize=false` + `Height=ControlHeight` + `TextAlign=MiddleLeft`**，否则"盒心对齐了、文字还是偏高"。CheckBox 同理。
- **跨页签一致**：应用与写字预览 = 左 360 卡片列 + 右竖直 Split（应用报告 / 写字程序预览，各带灰标题）；区域排版 = 左 360 卡片列 + 右 RegionCanvas Fill（自带 Dock=Fill）。
- 顺手修：`AddOverride` 改为 `(UiGroup, label, key)` 带标签；补回被漏掉的「笔起点」ToolTip。
- 探针新增两类断言：①同页签所有卡片 `Left`/`Width` 相同且不塌陷（h≥24）；②同一视觉行内控件垂直中心偏差 ≤1px。**结果 SETUP_TABS=ok**，外壳冒烟 MODERN/CLASSIC/APP_RUN 全过。
