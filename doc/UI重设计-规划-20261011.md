# AutoWriter 主界面重设计规划（2026-10-11）

参考：`doc/写字功能图片/`（奎享雕刻正式版三栏布局）
目标：**重新设计整个软件 UI，功能不变**。排版参考奎享：顶栏 + 左栏（内容/页面）+ 中央大画布 + 右栏（连接/控制/书写）+ 底部状态栏。

## 一、现状结构（改造基础）

主窗体 `MainForm`（Designer 5064 行）顶层结构：

```
MainForm
├─ menuStrip1            菜单：File / GCode creation / GCode transform / Machine control / About + 运行时 AutoWriter 菜单
├─ statusStrip1          状态栏
├─ splitContainer1
│  ├─ Panel1: tLPLinks（左列）
│  │   ├─ ucStreaming    「G代码流」绿色▶ 开始 / ⏸ / ■ / 进度条 / 时间
│  │   ├─ ucOverrides    进给/主轴倍率
│  │   ├─ ucFlowControl  流量面板（! ~ 重置 / 解锁 / 置零 已定制）
│  │   ├─ ucSetOffset    原点/偏移
│  │   └─ fCTBCode       G 代码编辑器（含行号、折叠）
│  └─ Panel2: tLPRechts（右区）
│      ├─ tLPRechtsOben: ucdro（坐标 DRO + 置零按钮）+ splitContainer2（GbCustomButtons + ucToolList ｜ 2D 视图）
│      └─ tLPRechtsUnten
│          ├─ tLPMitteUnten: pictureBox1（2D 预览大图）+ 底部信息行
│          └─ tLPRechtsUntenRechts: ucMoveToGraphic / ucSetCoordinateSystem / ucMoveToZero / ucJogControlAll
└─ writingPageBar（运行时加，Dock=Bottom，逐页换纸确认条）
```

关键点：**所有功能块都是独立 UserControl**。事件、发送管线、暂停/恢复/终止安全逻辑（R1–R6、候选 J/K、解锁、置零、重置守卫）全部挂在这些控件和 MainForm partial class 上——**绝不动功能代码，只搬家 + 换皮**。

串口连接 UI 目前在独立窗口 `ControlSerialForm`（COM CNC 常驻单实例，勿动其行为）。

### 皮肤风格
- 浅色现代风：背景 `#F0F2F5`，卡片白底圆角感（WinForms 用平边框 + 留白模拟），主色蓝 `#2D6CDF`，危险操作用红。
- 字体统一微软雅黑 9pt，标题 10pt 加粗；GroupBox 换成无边框 Panel + 标题栏样式。
- 书写「开始」用大号绿色主按钮（奎享的「书写」位），暂停黄、终止红。
- 状态栏右侧显示固件版本（1.3a.20221114）与连接状态灯。

## 三、实施方案对比

| 方案 | 做法 | 风险 | 结论 |
|---|---|---|---|
| A. 运行时重排（推荐） | 新增 `AutoWriter/Ui/ModernShell.cs`，在 `InitializeComponent()` 之后把控件 **re-parent** 到新三栏容器，统一样式；Designer/resx/事件零改动；设置项 `guiModernLayout` 可一键切回经典布局 | 低：控件引用关系不变；布局问题只影响"看" | ✅ 采用 |
| B. 重写 Designer | 直接改 5064 行 Designer + 14 个语言 resx | 极高：事件接线、本地化、LayoutSettings 守卫全要重做 | ❌ |
| C. 新 Form 壳 | 另写主窗体复用服务层 | 高：20+ 个 partial class 与控件深耦合，等于重写前端 | ❌ |

方案 A 与安全记录兼容：不碰 resx 的 LayoutSettings、不加新列到既有 TableLayoutPanel（四坑全部绕开），新容器全部运行时代码创建（与 writingPageBar 同模式，已有先例）。

## 四、分阶段计划

- **阶段 U1（本次核心）**：三栏骨架 + 控件搬迁 + 基础皮肤
  - 新建 `AutoWriter/Ui/ModernShell.cs`（容器树、re-parent、样式器）、`UiTheme.cs`（颜色/字体常量 + 按钮扁平化）
  - 顶栏大图标工具条（文件/写字/设置/窗口/工具/帮助 → 触发现有菜单项）
  - 设置 `guiModernLayout`（默认开），经典布局随时可切回
  - 守卫测试：`scripts/test-modern-shell.ps1`（反射构造 MainForm，断言各 UC 的新父容器与可见性；经典模式断言原结构不变）
- **阶段 U2**：左栏「内容/页面」面板（写字/区域/SVG/图片入口 + 页面参数摘要 + 模板下拉），右栏「连接」组接串口状态
- **阶段 U3**：皮肤打磨（图标、DPI、GroupBox→标题栏卡片、状态灯），MachineSetupForm / RegionTemplateForm 弹窗美化
- **阶段 U4**（可选）：参考图 03–12 的设置弹窗重排（软件设置/笔控/字体管理等）

每阶段走完 `scripts/build.ps1` + 冒烟脚本；**不提交 git**，删除走回收站；实机验证用 `scripts/start-autowriter.ps1 -Mode Normal`。

## 五、明确不做

- 不新增/删除任何功能与菜单项；不改发送、暂停、恢复、终止、置零、解锁的任何逻辑。
- 不动 `ControlSerialForm`（COM CNC）常驻单实例模式与 `WritingCommandGuard`。
- 不改 `$3=5`、`yDirection=+1`、2D 渲染方向；预览仍旧"所见即纸面"。
- 不动 14 个语言 resx；新 UI 文案只做中文（AutoWriter 菜单已是硬编码中文，同模式）。
